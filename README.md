# 나은 비서실

나은님 전용 비서실 대시보드 (GitHub Pages 정적 페이지).

- `index.html` — 앱 본체 (단일 파일, 이미지 Base64 인라인)
  - 오피스 맵: 빈 방 배경 위에서 10명 캐릭터가 몇 초마다 자리를 옮깁니다
  - 트래커: 체험단·설문·응모·상품권 집계와 노션 공용 허브 요약
- `build-tracker.py` — 트래커 탭 HTML/CSS 생성 (노션 기록 → 수치)
- `build-people.py` — 오피스 맵 캐릭터·스프라이트 인라인 생성
- `deploy.sh` — 커밋·푸시 후 Pages 반영 확인

페이지는 `noindex`이고 개인 식별 정보·계정 핸들은 넣지 않습니다.
